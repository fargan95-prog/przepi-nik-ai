# Przepiśnik AI

Aplikacja PWA do prowadzenia własnej książki kucharskiej. Pliki aplikacji będą umieszczone w katalogu głównym repozytorium.

Nie umieszczaj kluczy API ani tokenów w repozytorium. Przepisy są obecnie przechowywane lokalnie w przeglądarce; synchronizacja między urządzeniami wymaga osobnej bazy danych.
